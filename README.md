# 온고뷰티 브랜드 홈페이지

남성·여성의 머릿결을 관리하는 고데기, 매직기, 헤어드라이기 브랜드 **온고뷰티**의 정적 홈페이지입니다.

## 페이지

- `index.html` — 홈
- `about.html` — 내 소개
- `products.html` — 제품
- `stories.html` — 이야기
- `contact.html` — 연락하기

## 실행

빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하면 페이지 사이를 더 안정적으로 이동할 수 있습니다.

```bash
python -m http.server 8000
```

현재 제품명, 사양, 연락처, 블로그 글은 자연스러운 임시 내용으로 작성되어 있습니다.
